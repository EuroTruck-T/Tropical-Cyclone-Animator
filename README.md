# Tropical Cyclone Animator (TCA)

**Tropical Cyclone Animator** is a tool for creating and rendering tropical cyclone animations.

This repository is the public information and documentation home for TCA.

## About TCA

TCA is designed to help users create tropical cyclone animations and render them locally. Further product details, supported platforms, and availability information will be published here as they are confirmed.
